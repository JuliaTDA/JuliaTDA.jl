# Reprodução de papers com JuliaTDA

O primeiro experimento executado é o **Mapper em Reaven–Miller**, do paper
de Singh, Mémoli e Carlsson (2007). O resultado atual é uma reprodução
qualitativa parcial, com dados de procedência verificada, scripts executáveis,
figuras e uma análise de sensibilidade. Veja [o protocolo e os resultados](mapper2007/README.md).

Para cada reprodução, guardar a origem e o checksum dos dados, as escolhas
publicadas e as escolhas necessárias para completar o protocolo, os parâmetros

visualmente semelhante não estabelece equivalência entre as análises.
