# P2 expansion workflows

The P2 APIs are exposed by `using JuliaTDA`. MultiparameterPersistence is bundled
as a separate Julia package under `lib/MultiparameterPersistence`. Optional stacks
are loaded through package extensions.

| Track | Entry points | Optional stack |
|---|---|---|
| Euler descriptors | `cubical_ecc`, `ect`, `sect`, `euler_table` | None |
| Multiparameter | `bifiltration`, `hilbert_function`, `bigraded_betti`, `euler_surface`, `signed_measure` | MLJ for transformer |
| Explanatory chains | `optimal_cycle`, `optimal_volume` | JuMP + HiGHS |
| Time series | `delay_embedding`, `suggest_delay`, `sliding_window_ph` | DelayEmbeddings; compatible with DynamicalSystems states |
| Cubical images | `ImageFiltration`, `image_persistence` | MLJ for transformer |
| Trainable Mapper | `MLPFilter`, `optimize_filter`, `flux_filter`, `lux_filter` | Zygote + Optimisers; Flux/Lux adapters |

Resolve the local example environment with `julia examples/p2/setup.jl`, then run
any example using `julia --project=examples/p2 examples/p2/euler_images.jl`. The folder
contains six executable workflows, including two time-series examples and a measured
linear/nonlinear filter comparison.

Multiparameter computations are exact over F₂ on finite grids and intended for small
complexes. Koszul Betti numbers are module generators/relations/syzygies. Include all
critical grades when comparing to an unsampled module. Gaussian Euler-measure features
have a matched-grade Lipschitz bound for fixed combinatorics; this does not establish
unconditional stability of raw homology Hilbert measures. See the bundled package README.

Image masks use a vertex-based cubical convention. The exact SECT integral centers
on a shared threshold interval. Optimal cycles/volumes use certified F₂ integer programs
on Rips/Custom; higher-dimensional input must be a homology cycle representative.
Time-series windows refer to embedded indices and overlap induces dependence.
