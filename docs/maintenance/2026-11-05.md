## Reproduce

From a checkout of this repository:

```sh
julia scripts/setup.jl /tmp/shape-analysis
julia --project=/tmp/shape-analysis -e 'using Pkg; Pkg.add("CairoMakie"); Pkg.test("JuliaTDA")'
julia --project=/tmp/shape-analysis scripts/smoke.jl
julia docs/setup.jl
JULIATDA_DOCS_DEPLOY=false julia --project=docs docs/make.jl
julia examples/setup.jl
julia --project=examples examples/tuned_ph_pipeline.jl
```

For sibling development, add `--local` to setup. To check the supported umbrella
minimum, repeat setup and tests using Julia 1.10 in a separate environment.

## Older TDARipserer support

The Julia 1.6 resolver selected DataStructures 0.18.22 with the retained compat
range. Forcing 0.19 on that Julia version is incompatible with the registered
Graphs versions: Graphs releases accepting DataStructures 0.19 require a newer
Julia. Retaining 0.17/0.18 is therefore necessary. Execution of the additional
Julia 1.6 chain/PH spot check could not complete because the installed 1.6
runtime was removed externally during the check. No 1.6 execution pass is
claimed here; the complete 1.12.5 suite with 0.19.6 is the PR validation.
