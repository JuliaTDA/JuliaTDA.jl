Homology and inference API

This page collects the diagram, inference, multiparameter and optional PH APIs used in the umbrella examples. The statistical target and geometric convention remain those of the owning package; choose a method with Choosing a workflow. For point geometry and Mapper, see Geometry, Mapper and visualization API.

Diagram vectorizations (TDAPersistenceDiagrams.jl)

TDAPersistenceDiagrams.PersistenceCurve — Type
PersistenceCurve

Persistence curves offer a general way to transform a persistence diagram into a vector of numbers.

This is done by first splitting the time domain into buckets. Then the intervals contained in the bucket are collected and transformed by applying fun to each of them. The result is then summarized with the stat function. If an interval is only parially contained in a bucket, it is counted partially.

Once a PersistenceCurve is constructed (see below), it can be called to convert a persistence diagram to a vector of floats.

Constructors

  • PersistenceCurve(fun, stat, start, stop; length=10, integrate=true, normalize=false): length buckets with the first strating on t_start and the last ending on t_end.
  • PersistenceCurve(fun, stat, diagrams; length=10, integreate=true, normalize=false): learn the start and stop parameters from a collection of persistence diagrams.

Arguments

  • length: the length of the output. Defaults to 10.
  • fun: the function applied to each interval. Must have the following signature. fun(::AbstractPersistenceInterval, ::PersistenceDiagram, time)::T
  • stat: the summary function applied the results of fun. Must have the following signature. stat(::Vector{T})::Float64
  • normalize: if set to true, normalize the result. Does not work for time-dependent funs. Defaults to false. Normalization is performed by dividing all values by stat(fun.(diag)).
  • integrate: if set to true, the amount of overlap between an interval and a bucket is considered. This prevents missing very small bars, but does not work correctly for curves with time-dependent funs where stat is a selection function (such as landscapes). If set to false, the curve is simply sampled at midpoints of buckets. Defaults to true.

Call

(::PersistenceCurve)(diagram; normalize, integrate)

Transforms a diagram. normalize and integrate override defaults set in constructor.

Example

julia> diagram = PersistenceDiagram([(0, 1), (0.5, 1), (0.5, 0.6), (1, 1.5), (0.5, Inf)]);

julia> curve = BettiCurve(0, 2, length = 4)
PersistenceCurve(always_one, sum, 0.0, 2.0; length=4, normalize=false, integrate=true)

julia> curve(diagram)
4-element Vector{Float64}:
 1.0
 3.2
 2.0
 1.0

TDAPersistenceDiagrams.PersistenceImage — Type
PersistenceImage

PersistenceImage provides a vectorization method for persistence diagrams. Each point in the diagram is first transformed into birth, persistence coordinates. Then, it is weighted by a weighting function and widened by a distribution (default: gaussian with σ=1). Once all the points are transformed, their distributions are summed together and discretized into an image.

The weighting ensures points near the diagonal have a small contribution. This ensures this representation of the diagram is stable.

Once a PersistenceImage is constructed (see below), it can called like a function to transform a diagram to an image.

Infinite intervals in the diagram are ignored.

Constructors

PersistenceImage(ylims, xlims; kwargs...)

Create an image ranging from ylims[1] to ylims[2] in the $y$ direction and equivalently for the $x$ direction.

PersistenceImage(diagrams; zero_start=true, margin=0.1, kwargs...)

Learn the $x$ and $y$ ranges from diagrams, ensuring all diagrams will fully fit in the image. Limits are increased by the margin. If zero_start is true, set the minimum y value to 0. If all intervals in diagrams have the same birth (e.g. in the zeroth dimension), a single column image is produced.

Keyword Arguments

  • size: integer or tuple of two integers. Determines the size of the array containing the image. Defaults to 5.

  • distribution: A function or callable object used to smear each interval in diagram. Has to be callable with two Float64s as input and should return a Float64. Defaults to a normal distribution.

  • sigma: The width of the normal distribution mentioned above. Only applicable when distribution is unset. Defaults to twice the size of each pixel.

  • weight: A function or callable object used as the weighting function. Has to be callable with two Float64s as input and should return a Float64. Should equal 0.0 for x=0, but this is not enforced. Defaults to function that is zero at $y=0$, and increases linearly to 1 until slope_end is reached.

  • slope_end: the relative $y$ value at which the default weight function stops increasing. Defaults to 1.0.

Example

julia> diag_1 = PersistenceDiagram([(0, 1), (0, 1.5), (1, 2)]);

julia> diag_2 = PersistenceDiagram([(1, 2), (1, 1.5)]);

julia> image = PersistenceImage([diag_1, diag_2])
5×5 PersistenceImage(
  distribution = TDAPersistenceDiagrams.Binormal(0.5499999999999999),
  weight = TDAPersistenceDiagrams.DefaultWeightingFunction(1.65),
)

julia> image(diag_1)
5×5 Matrix{Float64}:

 0.344223  0.355089  0.338991  0.308795  0.268592

Statistical inference (PersistenceInference.jl)

Choose a method by its experimental unit and null assumptions, as explained in Choosing a workflow. A bootstrap radius, a mean-curve band and a permutation p-value answer different questions.

PersistenceInference.bootstrap_diagram — Function
bootstrap_diagram(X; n_boot=100, alpha=0.05, dim_max=1,
                  subsample_size=nothing, distance=Bottleneck(),
                  rng=Random.default_rng(), ripserer_kwargs...)

Compute empirical bootstrap diagram-distance radii for the point cloud X, motivated by the confidence-set framework of Fasy et al. (2014).

X is a vector of points; each point may be a Tuple, an SVector, or any type accepted by TDARipserer.ripserer. A MetricSpaces.EuclideanSpace works directly because it is a vector of SVector points.

Method

  1. Compute the reference diagrams ripserer(X; dim_max, ripserer_kwargs...).
  2. For b in 1:n_boot, draw a resample of X with replacement of size subsample_size === nothing ? length(X) : subsample_size, compute its diagrams, and record the matching distance between the reference and bootstrap diagram separately in each homology dimension.
  3. The confidence-set radius c in dimension d is the empirical (1 - alpha) quantile of those n_boot distances.

For a validly calibrated bottleneck confidence radius c, a finite bar longer than 2c cannot be matched to the diagonal inside that confidence ball. Stability explains this geometric threshold; it does not by itself establish coverage of this empirical resampling scheme for an arbitrary population target. The function does not estimate a support/density model or apply an m/n normalization. Radii are per dimension, without a simultaneous correction across dimensions. See significant and the point-cloud inference tutorial for interpretation.

Arguments

  • X: the point cloud (a vector of points).
  • n_boot=100: number of bootstrap resamples.
  • alpha=0.05: significance level; the confidence set has level 1 - alpha.
  • dim_max=1: maximum homology dimension to compute.
  • subsample_size=nothing: resample size. nothing means the full sample size length(X) (the standard nonparametric bootstrap). A smaller value gives an m-out-of-n bootstrap with replacement, not subsampling without replacement. The raw quantile is not rescaled, so its calibration can differ.
  • distance=Bottleneck(): a TDAPersistenceDiagrams matching distance, callable as distance(d1, d2). Bottleneck() matches Fasy et al.; Wasserstein(q) is also accepted.
  • rng=Random.default_rng(): random number generator, for reproducibility.
  • ripserer_kwargs...: forwarded to ripserer (e.g. modulus, threshold).

Returns

A BootstrapResult.

Example

using PersistenceInference, Random

# noisy circle
rng = Random.Xoshiro(42)
n = 60
θ = range(0, 2π; length = n + 1)[1:n]
X = [(cos(t) + 0.05 * randn(rng), sin(t) + 0.05 * randn(rng)) for t in θ]

result = bootstrap_diagram(X; n_boot = 100, alpha = 0.05, dim_max = 1, rng = rng)
significant(result, 1)   # the loop of the circle, distinguishable from noise

See also

  • significant, BootstrapResult, permutation_test.
PersistenceInference.BootstrapResult — Type
BootstrapResult

Result of bootstrap_diagram: empirical bootstrap diagram-distance radii and the reference persistence diagrams of a point cloud.

Fields

  • diagrams::Vector{<:PersistenceDiagram}: the reference diagrams computed from the full sample, one per homology dimension 0:dim_max.
  • radius::Vector{Float64}: the per-dimension confidence-set radius c, i.e. the (1 - alpha) quantile of the bootstrap distances. The selection helper retains finite features longer than 2 * radius[d + 1]; a confidence interpretation requires justified bootstrap calibration for the target.
  • distances::Vector{Vector{Float64}}: the raw bootstrap distances, one vector of length n_boot per homology dimension.
  • alpha::Float64: the significance level used.
  • n_boot::Int: the number of bootstrap resamples used.

See also

  • significant to extract the features distinguishable from noise.
PersistenceInference.significant — Function
significant(result::BootstrapResult, dim::Integer)

Return the intervals of the reference diagram in homology dimension dim whose persistence exceeds 2 * result.radius[dim + 1]. Interpreting these as features distinguishable from noise requires a valid confidence radius; the helper does not itself verify bootstrap coverage.

In the confidence-set picture of Fasy et al. (2014), the band of half-width c = radius[dim + 1] around the diagonal is the region where points cannot be told apart from noise; an interval (b, d) is significant exactly when its distance to the diagonal, (d - b) / 2, exceeds c, i.e. when death - birth > 2c.

Arguments

  • result: a BootstrapResult.
  • dim: the homology dimension (0-based, as in ripserer).

Returns

A vector of PersistenceIntervals (a subset of result.diagrams[dim + 1]). Infinite intervals are always returned by convention. Their retention is not statistical evidence for essential features; a truncated filtration may leave classes unresolved.

Example

result = bootstrap_diagram(X; dim_max = 1)
significant(result, 1)   # the significant loops
PersistenceInference.permutation_test — Function
permutation_test(X, Y; n_perm=1000, dim=1, q=2, dim_max=dim,
                 rng=Random.default_rng(), progress=false,
                 ripserer_kwargs...)

Permutation test for whether two point clouds X and Y have different persistent homology in dimension dim, following Robinson & Turner (2017).

X and Y are vectors of points of the same kind accepted by TDARipserer.ripserer (tuples, SVectors, or a MetricSpaces.EuclideanSpace, which is a vector of points). They must contain points of compatible type so they can be pooled.

Method

The test statistic is the q-Wasserstein loss W_q^q between the dimension-dim persistence diagrams of X and Y (the "joint loss" of Robinson & Turner with a single diagram per group). Under the null hypothesis that X and Y are drawn from the same distribution, the group labels are exchangeable, so:

  1. Compute the observed statistic from diagram(X) and diagram(Y).
  2. For each of n_perm permutations: pool all points of X and Y, randomly split them into two groups of the original sizes, recompute the two diagrams and the statistic.
  3. The p-value is (1 + #{perm stat ≥ observed}) / (1 + n_perm).

The +1 in numerator and denominator (Phipson & Smyth 2010) keeps the p-value in (0, 1], with minimum 1/(n_perm+1). Under the exchangeable null it gives a conservative Monte Carlo permutation test; this function samples permutations rather than enumerating the full distribution. Paired, clustered or dependent samples need design-specific randomization not implemented here.

Cost

This is O(n_perm × cost(ripserer)). Each permutation recomputes persistent homology of each relabelled group. TDARipserer is fast on small clouds, but keep n_perm and the cloud sizes modest, or be patient. The default examples in this package are intentionally tiny.

Arguments

  • X, Y: the two point clouds.
  • n_perm=1000: number of random permutations.
  • dim=1: homology dimension to test.
  • q=2: order of the Wasserstein distance (the statistic is W_q^q).
  • dim_max=dim: maximum homology dimension to compute (must be ≥ dim).
  • rng=Random.default_rng(): random number generator, for reproducibility.
  • progress=false: when true, print sparse progress (roughly every 10%).
  • ripserer_kwargs...: forwarded to ripserer.

Returns

A PermutationTestResult.

Example

using PersistenceInference, Random

circle(n, σ, rng) = [(cos(t) + σ*randn(rng), sin(t) + σ*randn(rng))
                     for t in range(0, 2π; length = n+1)[1:n]]
blob(n, rng)      = [(2*rand(rng) - 1, 2*rand(rng) - 1) for _ in 1:n]

rng = Random.Xoshiro(1)
X = circle(30, 0.05, rng)
Y = blob(30, rng)

result = permutation_test(X, Y; n_perm = 99, dim = 1, rng = rng)
result.pvalue   # small: circle and blob differ topologically

See also

  • PermutationTestResult, bootstrap_diagram.
PersistenceInference.PermutationTestResult — Type
PermutationTestResult

Result of permutation_test: a two-sample permutation test comparing the persistent homology of two point clouds at a fixed homology dimension.

Fields

  • pvalue::Float64: the permutation p-value, (1 + #{perm stat ≥ observed}) / (1 + n_perm).
  • observed::Float64: the observed test statistic W_q^q between the diagrams of the two samples at dimension dim.
  • null_distribution::Vector{Float64}: the n_perm statistics computed under random relabellings of the pooled points.
  • n_perm::Int: the number of permutations used.
  • dim::Int: the homology dimension tested.

A small p-value is evidence against the exchangeable point-distribution null, detected through persistence diagrams in dimension dim. Equality of underlying topology alone does not ensure exchangeability or test validity.

PersistenceInference.confidence_band — Function
confidence_band(samples::AbstractMatrix; method=:multiplier, kwargs...)
confidence_band(diagrams::AbstractVector{<:PersistenceDiagram}; grid,
    representation=:landscape, k=1, method=:multiplier, kwargs...)

Simultaneous finite-grid confidence band for the population mean of i.i.d. curves or diagrams. method=:multiplier uses Gaussian multipliers; method=:bootstrap resamples entire curves with replacement. Both calibrate the supremum deviation, rather than separately constructing pointwise intervals. Other keywords are those of multiplier_bootstrap.

grid is fixed in advance. Landscape values are sampled exactly at the supplied times (not bucket-integrated); k must be positive. Landscapes ignore essential intervals. Betti curves count birth <= t < death, including essential intervals. All diagrams must represent the same homology dimension and independent sampling units. Do not treat bars or bootstrap replicas of one cloud as independent data. For a fixed finite grid, ordinary multivariate CLT/bootstrap conditions apply (finite second moments and nondegenerate stochastic coordinates); the landscape functional theory does not automatically extend to continuous Betti bands.

Example

using PersistenceInference, TDAPersistenceDiagrams, Random
rng = Xoshiro(42)
diagrams = [PersistenceDiagram([(0.0, 1 + rand(rng))]; dim=1) for _ in 1:80]
band = confidence_band(diagrams; grid=range(0, 2; length=101), rng=rng)
betti = confidence_band(diagrams; grid=band.grid, representation=:betti, rng=rng)
PersistenceInference.multiplier_bootstrap — Function
multiplier_bootstrap(samples::AbstractMatrix; grid=1:size(samples, 2),
    n_boot=1000, alpha=0.05, studentize=false, rng=Random.default_rng())
multiplier_bootstrap(diagrams; grid, representation=:landscape, k=1, kwargs...)

Gaussian multiplier bootstrap for the mean of independent functional samples. Rows are independent observations; columns are values on a fixed grid. Each replicate is n^(-1/2) * sum(ξᵢ * (fᵢ - mean(f))), with independent standard normal ξᵢ, and the supremum of its absolute values calibrates the band. studentize=true divides the process by pointwise sample standard deviations; zero-variance coordinates have zero width. Returns a ConfidenceBand.

For diagrams, use the same fixed grid for all independent diagrams, with representation=:landscape (k-th landscape) or :betti (pointwise Betti curve). See confidence_band for the statistical target and limitations.

Reference: Chazal et al. (2015), Stochastic convergence of persistence landscapes and silhouettes, https://doi.org/10.20382/jocg.v6i2a8.

PersistenceInference.ConfidenceBand — Type
ConfidenceBand

A simultaneous confidence band for a population mean on the finite grid. estimate, lower, and upper have one entry per grid point. maxima stores the bootstrap supremum statistics on the sqrt(n) scale; critical_value is their (1 - alpha) quantile. studentized records whether pointwise sample standard deviations were used. n_samples counts independent observations, not points in a single cloud. Coverage is asymptotic and applies to the supplied grid, not an unobserved continuum or individual future curves.

PersistenceInference.max_persistence_significance — Function
max_persistence_significance(diagram, null_diagrams; alpha=0.05)
max_persistence_significance(diagram, null_maxima::AbstractVector{<:Real}; alpha=0.05)
max_persistence_significance(X; null_sampler, n_null=999, dim=1,
    alpha=0.05, rng=Random.default_rng(), ripserer_kwargs...)

Test whether the longest finite bar exceeds those generated under an explicit global null. The Monte Carlo p-value is (1 + count(null_max >= observed))/(B+1). The threshold uses order ceil((1-alpha)*(B+1)), becoming Inf when the number of simulations cannot resolve alpha. Ties are conservative. Each interval is also compared to the null maximum, rather than to pooled null bars.

For point clouds, null_sampler(rng, length(X)) must generate an independent cloud under a scientifically justified null with the same design/sample size. The observed and null clouds use identical PH options. Resampling the observed cloud alone is not automatically a null model. Precomputed null diagrams must use the same filtration, homology dimension, sampling design, and units. Essential bars are excluded; an empty finite diagram has maximum zero.

Valid size requires exchangeability of the observed statistic and the simulated null statistics under the global null (known null parameters or a valid conditional randomization). Fitting a null to these observations requires separate calibration.

Example

using PersistenceInference, TDAPersistenceDiagrams
observed = PersistenceDiagram([(0.0, 3.0), (0.0, 0.1)]; dim=1)
result = max_persistence_significance(observed, fill(0.5, 99))
result.pvalue == 0.01
significant(result) # the long interval

Reference for Monte Carlo p-values: Phipson & Smyth (2010), https://doi.org/10.2202/1544-6115.1585.

PersistenceInference.MaxPersistenceResult — Type
MaxPersistenceResult

Monte Carlo test of the maximum finite persistence against a supplied null model. Contains observed, pvalue, the conservative threshold, null_maxima, alpha, and the observed diagram. interval_pvalues compares each finite interval against the null maximum, providing simultaneous control under the specified global null. Essential intervals have p-value 1 and are excluded from this test. significant extracts rejected intervals.

PersistenceInference.independence_test — Function
independence_test(X, Y; kernel_x=SlicedWassersteinKernel(),
    kernel_y=SlicedWassersteinKernel(), n_perm=999, rng=Random.default_rng())
independence_test(K::AbstractMatrix, L::AbstractMatrix; n_perm=999, rng=...)

Test independence of paired i.i.d. observations using the Hilbert-Schmidt independence criterion (HSIC). Diagram samples use Sliced Wasserstein kernels by default. Numeric observations may use a supplied kernel such as kernel_y=(x,y)->exp(-(x-y)^2/2). Matrix inputs are Gram matrices, not data matrices. Kernels must be symmetric and positive semidefinite.

For centered Gram matrices, the statistic is sum(Kc .* Lc)/n^2. Permutations jointly permute the rows and columns of L, breaking the pairing while preserving each marginal. P-values use (1 + count(null >= observed))/(n_perm + 1). The permutation test controls size under independence/exchangeability; sensitivity to all dependence alternatives additionally requires characteristic kernels. No universal consistency claim is made for the default diagram kernel. Do not permute individual points within one cloud as if they were independent diagram observations. Time series require an appropriate block/randomization design.

Reference: Gretton et al. (2008), A Kernel Statistical Test of Independence, https://papers.nips.cc/paper/2007/hash/d5cfead94f5350c12c322b5b664544c1-Abstract.html.

IndependenceTestResult

Multiparameter invariants

This bundled package uses exact F₂ algebra on finite grids for small complexes. See the P2 expansion workflows for the sampling and stability scope.

MultiparameterPersistence.Bifiltration — Type
Bifiltration(simplices, grades)

A finite, downward-closed simplicial complex with grades (scale, function). Vertex labels are positive integers. Every face must occur and have a componentwise smaller or equal grade. Coefficients throughout this package are F₂.

Supply one finite two-coordinate grade per nonempty simplex. The constructor sorts vertex labels, rejects duplicate simplices/repeated vertices, and orders the stored complex by simplex dimension and vertex labels. F.simplices[i] and F.grades[i] refer to the same simplex. A simplex is active at (r,a) when both grade coordinates are at most those thresholds.

MultiparameterPersistence.bifiltration — Function
bifiltration(points, values; dim_max=1, max_scale=Inf, max_simplices=20_000)

Function-Rips bifiltration: the grade of a simplex is its maximum pairwise Euclidean distance and maximum vertex function value. points are a vector of coordinate vectors (or a matrix with points in columns). Enumerates through dimension dim_max + 1, including the boundaries needed for Hdim_max. max_scale truncates the Rips complex. Enumeration is exponential: the explicit size limit prevents accidentally requesting a large dense research computation.

values contains one finite function value per point. Matrix input uses points in columns; vector input uses equally sized finite coordinate vectors. Scale is an edge-length threshold with no factor of two; vertices have scale grade 0. Function levels may be negative. Returns a Bifiltration.

The constructor includes all simplices of size at most dim_max+2 whose maximum edge length is at most max_scale. dim_max must be nonnegative, max_scale nonnegative (possibly Inf), and max_simplices at least the vertex count. Euler invariants concern this actual dimension-truncated complex, including the extra chain dimension, rather than a full Rips complex in all dimensions.

MultiparameterPersistence.GridInvariant — Type
GridInvariant(scales, levels, values)

A rectangular invariant with values[scale_index, level_index]. Both axes must be finite, nonempty and strictly increasing; the finite real-valued matrix must match their lengths. Axes are stored as Vector{Float64} and values as a matrix of the supplied real element type.

Implements Tables.jl's column interface with columns scale, level, and value. Flattened table order varies scale first, following vec(values). See signed_measure for mixed-difference encoding and reconstruction.

MultiparameterPersistence.hilbert_function — Function
hilbert_function(F; scales, levels, dim=0, max_grid=4096,
                 max_chain=2048, max_workspace=100_000_000)

Exact dimensions of Hdim at each grid grade over F₂. The complex must include dimension dim+1 if deaths in that dimension are to be represented.

Returns a GridInvariant whose entries are pointwise topological Betti counts, not free-resolution Betti numbers. Both axes must be finite, nonempty and strictly increasing. max_grid bounds their product; max_chain bounds the largest chain dimension; max_workspace guards its squared size. These limits are conservative dimension estimates, not measured byte allocations or runtime guarantees. See bigraded_betti for invariants using module maps.

MultiparameterPersistence.bigraded_betti — Function
bigraded_betti(F; scales, levels, dim=0, max_grid=4096,
               max_chain=2048, max_workspace=100_000_000)

Compute β₀, β₁, β₂ of the grid-discretized Hdim module via Koszul homology: M(i-1,j-1) → M(i-1,j) ⊕ M(i,j-1) → M(i,j). Returns (beta0, beta1, beta2) as GridInvariants. Values outside the lower grid boundary are zero; choose axes containing all critical grades to recover the original finite presentation's graded Betti numbers. These are module generators/relations/syzygies, not pointwise topological Betti numbers.

The three named outputs beta0, beta1, and beta2 describe generators, relations, and relations among relations of the Hdim module. In particular, beta2 is not H₂. Inclusion-map ranks are computed over F₂ by Boolean/XOR elimination. The cumulative sum in both directions of beta0.values - beta1.values + beta2.values reconstructs the sampled Hilbert function.

Grid/chain guards are those of hilbert_function, with the workspace estimate multiplied by the number of grid positions because homology spaces are retained. Above the upper grid boundary the sampled module extends constantly; no artificial death is inserted. Changing/coarsening the axes changes the sampled module and may omit intermediate features.

MultiparameterPersistence.euler_surface — Function
euler_surface(F; scales, levels, max_grid=4096)

Return the Euler characteristic at each supplied grade as a GridInvariant, using alternating counts of all active simplices in the constructed complex. Axes must be finite, nonempty and strictly increasing. The grid-size product is bounded by max_grid; no homology chain matrices are assembled.

The Euler characteristic equals the alternating sum of homology dimensions over every dimension of this complex. It need not equal H₀−H₁ if higher homology exists, including homology created by dimension truncation.

MultiparameterPersistence.SignedMeasure — Type
SignedMeasure(locations, weights)

A finite signed atomic measure, with atoms as columns of a 2×n matrix and one real weight per atom. Locations and weights must be finite and are stored as Float64. Negative weights and repeated locations are permitted; weights need not sum to one. An empty measure uses zeros(2,0) and Float64[].

See signed_measure for construction from invariant grids or exact Euler grades, and MeasureVectorizer for fixed-length numerical features.

MultiparameterPersistence.signed_measure — Function
signed_measure(G::GridInvariant)

Möbius (mixed finite-difference) measure of a Hilbert or Euler grid. Its cumulative sum reconstructs G.values exactly, taking values below the grid to be zero. No artificial death is added at the upper boundary: the grid extends constantly. Raw atomic measures and bigraded Betti arrays need not be stable in an unweighted norm. Stability claims require a chosen measure distance and bounded total variation.

signed_measure(F::Bifiltration)

Exact Euler measure, with mass (-1)^dimension at each simplex's actual grade. Its quadrant cumulative sum is the Euler surface without snapping grades to a sampling grid. For fixed simplex combinatorics, Gaussian vectorization is Lipschitz under matched grade perturbations, with total variation bounded by the number of simplices. Changing a truncation cutoff can change the combinatorics and is outside this bound. Use signed_measure(hilbert_function(...)) instead for the grid's homology Hilbert measure, whose stability has different conditions.

MultiparameterPersistence.MeasureVectorizer — Type
MeasureVectorizer(centers; bandwidth=1.0)

Fixed Gaussian test-function features of a signed measure. Centers are a 2×m matrix; outputs always have length m. For matched atoms, moving atoms by δ changes each feature by at most sum(abs, weights)*δ/(bandwidth*sqrt(exp(1))). This is a bounded-Lipschitz measure vectorization; it does not assert interleaving stability of an arbitrary homology Hilbert measure. Shared centers must be fitted on training data only. See measure_vectorizer_model for an optional MLJ adapter.

MultiparameterPersistence.measure_vectorizer_model — Function
measure_vectorizer_model(; bandwidth=1.0, resolution=(10,10), centers=nothing)

Create an optional MLJ signed-measure transformer. Install and load MLJModelInterface (or MLJBase) to activate the extension before calling it. Input is a vector of SignedMeasures or a Tables.jl table with a measure column. Output is a Tables-compatible named tuple of continuous feature columns measure_1, measure_2, etc., with one row per measure.

fit learns a rectangular grid of prod(resolution) Gaussian centers from training atom ranges unless a finite 2×m centers matrix is supplied. Constant ranges are widened by ±0.5; all-empty training atoms use [-1,1] on each axis. bandwidth must be finite and positive, and both resolution entries positive integers. transform reuses the fitted MeasureVectorizer; held-out atom ranges never update it. Fit centers inside each cross-validation training fold to avoid leaking held-out information. The model learns a representation, not a classifier or a statistical calibration.

TDARipserer.optimal_cycle — Function
optimal_cycle(f, interval; at=birth(interval), representative_kind=:cocycle,
              weights=nothing, tie_break=:lexicographic, max_cells=10_000)

Minimum weighted support in the selected homology class over F₂, on Rips or Custom simplicial filtrations. Requires using JuMP, HiGHS. The default converts an H₁ cocycle using reconstruct_cycle; for homology representatives (including higher dimensions), pass representative_kind=:cycle. at must be in the interval. weights is a vector in enumerated cell order or a function of a simplex; default unit weights minimize support size. The result's filling certifies z=c+∂y mod 2. Lexicographic tie breaking chooses the smallest binary support vector among solutions within tolerance of optimum, with one extra solve per cell. Use :solver for any optimal support. Only a solver-certified optimum is returned.

TDARipserer.optimal_volume — Function
optimal_volume(f, cycle::AbstractVector; at, weights, tie_break, max_cells)
optimal_volume(f, interval; at=death(interval), representative_kind=:cocycle, ...)

An essential interval has no finite death and needs an explicit finite at with a bounding chain. Infeasible fillings and non-optimal solver statuses are errors. Supported filtrations, weights and tie policy are as for optimal_cycle.
